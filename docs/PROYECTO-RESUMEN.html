📦 RESUMEN DEL PROYECTO - CV CARLOS FALLA

✅ LO QUE TIENES AHORA

Un CV profesional completo construido con Quarto que incluye:

📁 Archivos Principales

  • ✅ index.qmd - Tu CV (HTML interactivo)
  • ✅ cv-data.yml - TODOS tus datos (aquí editas TODO)
  • ✅ _quarto.yml - Configuración del proyecto
  • ✅ styles.css + custom.scss - Diseño personalizado
  • ✅ cv-carlos.Rproj - Proyecto de RStudio
  • ✅ README.md - Documentación completa
  • ✅ INICIO-RAPIDO.md - Guía paso a paso

🎨 Características del Diseño

✅ Layout de 2 columnas - Sidebar izquierda: Perfil, Educación, Software, Idiomas, Intereses - Contenido principal: Skills, Experiencia, Referencias

✅ Colores corporativos - Naranja (#FF9800) - Color principal - Cyan (#00BCD4) - Color secundario - Azul (#1976D2) - Acentos

✅ Secciones incluidas - 📊 Perfil con estadísticas (certificaciones) - 🎓 Educación - 💻 Software con niveles visuales (dots) - 🌍 Idiomas con barras de progreso - 🚀 Skills - 💼 Experiencia (timeline visual) - 👥 Referencias - 🎯 Intereses y Hobbies

✅ Responsive - Se adapta a móviles y tablets

✅ Exportable - HTML (web) - PDF (impresión)

🎯 CÓMO EMPEZAR (3 PASOS)

1. Abrir el Proyecto

Doble click en: cv-carlos.Rproj

2. Ver tu CV

# En RStudio, abre index.qmd y presiona "Render"
# O en la consola:
quarto::quarto_preview()

3. Editar Información

Abre: cv-data.yml
Edita lo que necesites
Guarda (Ctrl+S)
¡Listo!
